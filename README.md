# Fine-Tuning Encoder vs Decoder

Fine-Tuning de Encoder versus Few-Shot de Decoder para Classificação de Discurso Ofensivo em Português Brasileiro: uma Extensão Multi-Modelo do JabuticaBERT


O arquivo main_fakeNews, utiliza o Dataset desta versão: kauandivino/FakenewsBR. Com a tarefa de classificar textos como notícia falsa ou notícia verdadeira.
