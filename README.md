# Fine-Tuning Encoder vs Decoder

Fine-Tuning de Encoder versus Few-Shot de Decoder para Classificação de Discurso Ofensivo em Português Brasileiro: uma Extensão Multi-Modelo do JabuticaBERT


O arquivo main_fakeNews, utiliza o Dataset nesta versão: [kauandivino/FakenewsBR](huggingface.co/datasets/kauandivino/FakenewsBR). Com a tarefa de classificar textos como notícia falsa ou notícia verdadeira. 

O arquivo main_hateSpeech, utiliza o Dataset nesta versão: [franciellevargas/HateBR](https://github.com/franciellevargas/HateBR). Com a tarefa de classificar textos como ofensivo ou não ofensivo.
